01 02/2025 – 06/2025

RL Rotary Inverted Pendulum

Two Soft Actor-Critic agents trained on a Simscape model of the QUBE-Servo 2: one swings the pendulum up in about two seconds, the other keeps it balanced. The final policy runs on an ESP32 in real time.

  • The demo runs the exported actor networks of both agents (6 → 8 → 8 → 1 and 6 → 32 → 32 → 32 → 1).
  • Press Push to disturb it while it balances. If it falls, it resets and swings up again.
  • MATLAB
  • Simulink
  • SAC
  • ESP32
  • C++
Source code

Plant model rebuilt from the repo's motor and CAD parameters; actor weights from get_action_su.m / get_action_b.m.

02 2025 – Present

Drone RL: Crazyflie in Isaac Lab

Flight control for the Crazyflie 2.1 Brushless in Isaac Lab 3.0: a cascaded PID baseline and the same four layers learned with PPO, small enough for the on-board STM32, plus landing on an ArUco marker.

  • The demo flies a side-view model with the repo's tuned PID gains: position → velocity → attitude → rate.
  • Tap anywhere to set a target, or pick a route. Gust hits it with a sideways push.
  • Isaac Lab
  • PPO
  • rsl_rl
  • PID
  • Python
Source code

2-D simplification (34 g, 0.2 N per motor, 30 ms motor lag); drone drawn 2.5× size.

03 09/2024 – 10/2024

NeuroKit: Deep Learning from Scratch

A PyTorch-like framework written with NumPy only: tensors with autograd, layers, losses, and SGD / Adam / RMSprop optimizers, plus synthetic datasets to test them.

  • The demo is a JavaScript port of the same building blocks, training live on NeuroKit's own datasets.
  • Change the dataset, activation or optimizer and watch the decision boundary form.
  • NumPy
  • Autograd
  • Python
Source code

MLP 2 → 24 → 24 → 3, full-batch training on 200–300 points.
